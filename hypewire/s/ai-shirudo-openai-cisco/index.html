OpenAI and Cisco release Shirudo, an open-source runtime for AI-written security patches

OpenAI and Cisco released Shirudo, which loads temporary kernel protections on running Linux systems while real patches are prepared.

What happened

In a controlled test, a Codex-written shield blocked a Java4Shell exploit on a running server without a restart. It is pre-release and BSD-licensed, and deploying shields needs security-team approval.

Why it matters

It is a test of whether AI can write stopgap defences quickly when a new flaw appears.

Why the hype

  • First of its kindIt lets AI agents write and deploy kernel shields.
  • TimingIt arrives after a run of serious open-source flaws.

Background

eBPF is a Linux feature that lets small programs run safely inside the kernel, often used for security tools.

What to watch next

Watch for early adopters and whether the shields hold up outside controlled tests.
