NGINX fixes ten flaws, including bugs that could let attackers run commands

Researchers disclosed ten NGINX flaws, five of them memory-corruption bugs dubbed nginx2root, and F5 has released fixes.

By the numbers

10flaws disclosed
5memory-corruption bugs

What happened

Unauthenticated attackers could crash NGINX or, in some setups, run commands. A separate Linux kernel flaw could allow escalation to root. Fixes came on November 18. Cloudflare said exploitation had not been confirmed as of November 20.

Why it matters

NGINX runs a large share of the world's websites, so a flaw in it affects huge numbers of servers.

Why the hype

  • ScaleNGINX is one of the most used web servers.
  • RiskSome flaws can be triggered without logging in.
  • TimingFixes are out, so the race is on to patch.

Background

NGINX is open-source web server software, owned by F5 since 2019.

What to watch next

Watch for signs of attacks in the wild and patch adoption rates.
