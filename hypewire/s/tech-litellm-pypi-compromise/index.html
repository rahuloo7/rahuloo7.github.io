LiteLLM blames a leaked GitHub token for its poisoned release

LiteLLM says its release pipeline was hijacked on October 21 to push a malicious 1.107.0 build to PyPI and Docker.

By the numbers

1.107.0compromised version
Oct 21date of attack

What happened

LiteLLM suspects a GitHub token leaked in its AI gateway logs let attackers push version 1.107.0, The Hacker News reports. The build carried a credential stealer and a backdoor. The package was quarantined and the Docker images removed.

Why it matters

LiteLLM sits between many apps and AI models, so a bad release can reach a lot of systems.

Why the hype

  • RiskUnpinned installs during the attack window pulled the malicious build.
  • TrendAttacks on open source packages used by AI developers are rising.

Background

PyPI is the main public library of Python packages, used by millions of developers.

What to watch next

Watch for LiteLLM's full incident report and advice for users who installed the bad version.
