GitLab patches a maximum-severity flaw in self-managed servers

The bug, rated CVSS 10.0, lets attackers run code without logging in and affects releases back to 2014.

By the numbers

10.0CVSS severity score
2014affected since

What happened

GitLab released emergency patches for an integer overflow in its bundled Onigmo regex library, The Hacker News reports. It allows code execution without logging in on self-managed servers since version 7.0. GitLab says it knows of no active attacks.

Why it matters

Many companies host their own GitLab, which holds source code and deployment secrets.

Why the hype

  • Risk10.0 is the highest severity score on the CVSS scale.
  • ScaleSelf-managed releases going back to 2014 are affected, per the report.

Background

GitLab is a widely used platform for storing code and running software builds.

What to watch next

Watch for whether attackers begin targeting unpatched servers.
