Meta releases Muse Spark Open, a huge open-weight model that runs on two Macs

Meta's 816-billion-parameter Muse Spark Open model is built for coding and agents and can run on two Mac Studio machines.

By the numbers

816Btotal parameters
42Bactive parameters
1Mtoken context window

What happened

Meta released weights for Muse Spark Open, which uses 42 billion of its 816 billion parameters at a time and has a one-million-token context window. It was optimized with Apple to run on two M5 Ultra Mac Studios using Apple's MLX framework.

Why it matters

Open-weight releases this large let developers run top-tier AI on their own hardware rather than through an API.

Why the hype

  • RivalryMeta is pitching it against open-weight models from Chinese labs.
  • ScaleAt 816 billion parameters it is one of the largest open-weight models released.
  • Big nameApple helped optimize it to run on its Macs.

Background

Meta owns Facebook, Instagram and WhatsApp, and has released open-weight AI models for several years.

What to watch next

Watch for independent benchmark results and how developers test it against Chinese open-weight rivals.
